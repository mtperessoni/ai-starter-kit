# Workflow (WF)

Every change to product behavior follows **PRD, then TRD, then plan, then code**. Starting from the code reproduces the defect and loses the decision. The `prd-flow` skill runs this workflow; these are its rules in catalog form. Reference files named below are the five of prd-flow lite (decision L18): `dispatch.md`, `survey.md`, `sheet.md`, `write.md`, `run.md`, plus `repo.md`; the old file to new heading map is `proposals/lite-reference-map.md`.
