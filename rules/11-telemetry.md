# Run telemetry (TM)

Every agent run leaves summarized artifacts, grouped by the change it served; at the end of a delivery a retrospective names what was slow, expensive, looping or wasteful. A run within every threshold produces no finding. The design is in `proposals/run-telemetry.md`; these are the rules a project follows.

| ID | Rule | Why | Lands in |
|---|---|---|---|
| TM01 | Artifacts live in `.ai-kit/runs/<context>/` and are git-ignored: `meta.json`, `events.jsonl`, `resources.jsonl`, and the retro outputs `spans.jsonl`, `summary.json`, `retro.md`. When the context is a change folder, `retro.md` is also copied to `changes/NNN-<slug>/retro.md`, which is committed and archived with the change | Cost and time were guessed from memory; the evidence must outlive the session and stay with the change | `.gitignore` (`gitignore.kit`); `scripts/retro.py`; `changes/` |
| TM02 | The context is, first match wins: env `AI_KIT_CONTEXT`; the first line of `.ai-kit/runs/current`; the git branch with `/` turned into `-`; `default`. prd-flow step 1 writes the slug with `scripts/gates.sh context <slug>` | Runs of one change must group together, and parallel changes must not mix | `.claude/skills/prd-flow/SKILL.md`; `scripts/gates.sh context` |
| TM03 | `scripts/telemetry_hook.py` is the only hook command, registered async in `.claude/settings.json` for SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, PostToolUseFailure, SubagentStart, SubagentStop, Notification, PreCompact, PostCompact, Stop and SessionEnd. It appends one line to `events.jsonl`, prints nothing, always exits 0, finishes in under 100 ms and swallows every exception | A recorder that can block or slow a run changes what it measures | `.claude/settings.json`; `scripts/telemetry_hook.py` |
| TM04 | Tool outputs are never stored: only sizes, durations, hashes and the first 160 characters of a command or path. Secrets are redacted before writing: `KEY=value` with TOKEN, SECRET, PASSWORD, KEY or AUTH in the key, bearer tokens, `sk-`, `ghp_`, `gho_` and `AKIA` strings become `***` | The log is read by agents and sits in the working tree; it must never leak a credential or fill the disk | `scripts/telemetry_hook.py`; `scripts/run_probe.py` |
| TM05 | Test and build targets of `scripts/gates.sh` (`related`, `one`, `offline`, `integration`, `full`, `build`) run through `scripts/run_probe.py`, which streams the output unchanged, returns the exit code and appends time, memory peak, disk before and after, tests collected and failed to `resources.jsonl` | Hooks see durations but not memory, disk or test counts | `scripts/gates.sh`; `scripts/run_probe.py` |
| TM06 | After the full suite (TS03), run `scripts/gates.sh retro`. It reads the artifacts, writes `spans.jsonl`, `summary.json` and `retro.md`, prints at most 15 lines and never fails the caller; a missing source lowers the coverage, it does not raise | One look at the end of a delivery is cheap; watching during the run is not | `.claude/skills/prd-flow/reference/execution.md` (E20); `AGENTS.md`; `scripts/retro.py` |
| TM07 | `retro.md` lists Coverage, Findings, Time and tokens, Top 5. Findings are only metrics past a threshold, each with severity, value, threshold, evidence (event numbers, agent, command) and the rule it breaks or `candidate`. With none, it says the run stayed within every threshold in one line | A report that always has findings trains everyone to skip it | `scripts/retro.py` |
| TM08 | Thresholds live in `ai-kit.json` `telemetry` (`long_call_s`, `long_test_s`, `long_subagent_min`, `subagent_tokens`, `subagent_tools`, `context_peak_tokens`, `big_output_kb`, `loop_repeats`, `edit_repeats`, `error_rate`, `memory_mb`, `disk_drop_mb`, `dead_mb`, `max_events_mb`, `keep_days`). A project tunes a value there; nothing is hardcoded in the scripts | One project's normal is another's finding | `ai-kit.json`; `scripts/retro.py` |
| TM09 | The final report of a delivery lists the retro findings, or says the run stayed within every threshold | A finding nobody reads changes nothing | `.claude/skills/prd-flow/SKILL.md` "Final"; `reference/execution.md` (E20) |
| TM10 | Detectors map to the rules they police: a `test.full` inside a subagent or repeated before the last is TS03; a subagent past the token or tool ceiling is SA15, SA16; Docker outside `gates.sh` is TS29; unbounded background output is TS34. A metric with no rule is reported as `candidate` | A finding that cites a rule can be acted on; one that does not is a proposal | `scripts/retro.py` |
| TM11 | `events.jsonl` past `max_events_mb` drops its oldest half and writes a `truncated` marker; `scripts/gates.sh retro --prune` and `clean-outputs` delete run folders older than `keep_days` and those of archived changes. `/ai-kit update` never touches `.ai-kit/runs/` | The log must not become the next disk problem | `scripts/telemetry_hook.py`; `scripts/retro.py`; `scripts/clean_task_outputs.py` |
| TM12 | The kit's hooks are merged into an existing `.claude/settings.json`; the project's own hooks are never dropped or reordered | The file is the project's; telemetry is an addition | `installer/ai-kit/reference/ownership.md`, `install.md` |
| TM13 | The retro adds a `doc_reads` finding: the doc and skill files read most in the run (Read calls and rereads per file, with bytes), top 5, flagged when one file is read more than the `ai-kit.json` threshold | Which docs cost the most context was guessed; the CE rules need that evidence | `scripts/retro_detectors.py`; `ai-kit.json` `telemetry` |
