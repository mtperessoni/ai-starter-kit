# Ruby

## Detect
| Signal | Means |
|---|---|
| `Gemfile`, `Gemfile.lock` | Bundler: prefix with `bundle exec` |
| `spec/` and `rspec` | RSpec |
| `test/` and `minitest` | Minitest: replace the rspec commands with `bin/rails test` or `ruby -Itest` |
| `config/application.rb` | Rails: source in `app/`, features often in `app/<domain>` or `packs/` |
| `.rubocop.yml` | RuboCop configured |

## Commands
| Key | Value |
|---|---|
| `commands.test` | `bundle exec rspec` |
| `commands.offline_args` | `--tag ~integration` |
| `commands.integration_args` | `--tag integration` |
| `commands.no_coverage_args` | `COVERAGE=false` (when SimpleCov reads it) |
| `commands.lint` | `bundle exec rubocop` |
| `commands.fix` | `bundle exec rubocop -a` |
| `commands.import_check` | `bundle exec rails zeitwerk:check` (Rails) or `ruby -c` on changed files |
| `tests.runner` | `bundle exec rspec {files}` |
| `tests.native_related` | empty |
| `tests.failure_regex` | `^rspec (\S+)` |

## Structure enforcement
- RuboCop `Metrics/MethodLength` (Max 80), `Metrics/ClassLength` (Max 300), `Metrics/ModuleLength`.
- Import direction (AR09): `packwerk` packages with dependency checks, one package per feature.
- Baseline: `.rubocop_todo.yml` (generated by `rubocop --auto-gen-config`) and `package_todo.yml` for packwerk; shrink-only.

## Offline guard
WebMock with `WebMock.disable_net_connect!(allow_localhost: true)`; under the offline flag, `allow_localhost: false`.

## CI setup
```yaml
      - uses: ruby/setup-ruby@v1
        with:
          bundler-cache: true
```

## Ignore
`**/vendor/**`, `**/tmp/**`, `**/log/**`, `**/coverage/**`.
