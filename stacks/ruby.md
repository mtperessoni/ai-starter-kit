# Ruby

## Detect
| Signal | Means |
|---|---|
| `Gemfile`, `Gemfile.lock` | Bundler: prefix with `bundle exec` |
| `spec/` and `rspec` | RSpec |
| `test/` and `minitest` | Minitest: replace the rspec commands with `bin/rails test` or `ruby -Itest` |
| `config/application.rb` | Rails: source in `app/`, features often in `app/<domain>` or `packs/` |
| `.rubocop.yml` | RuboCop configured |

## Structure enforcement
- RuboCop `Metrics/MethodLength` (Max 80), `Metrics/ClassLength` (Max 300), `Metrics/ModuleLength`.
- Import direction (AR09): `packwerk` packages with dependency checks, one package per feature.
- Baseline: `.rubocop_todo.yml` (generated by `rubocop --auto-gen-config`) and `package_todo.yml` for packwerk; shrink-only.

| Rule | Tool | Baseline |
|---|---|---|
| AR24 complexity | RuboCop `Metrics/CyclomaticComplexity` (Max 10), `Metrics/PerceivedComplexity`, `Metrics/BlockNesting` (Max 4), `Metrics/ParameterLists` (Max 5) | `.rubocop_todo.yml` |
| AR25 dead code | `debride` (`debride lib app`, with a whitelist for Rails-reached methods), `Lint/UselessAssignment`, `Lint/UnusedMethodArgument`; `traceroute` for unused Rails routes and actions | whitelist file, shrink-only |
| AR26 duplicates | `flay` (`flay app lib`) or `jscpd` | report of today |
| AR27 typing | Sorbet `# typed: strict` per file (`srb tc`) or RBS with Steep, when the project uses one; otherwise not applicable. Strictness per file only goes up | files below `strict` listed |
| AR22 dispatch | RuboCop `Style/Send`, `Lint/SendWithMixinArgument`; `send(`, `public_send(`, `constantize`, `define_method` with computed names, `method_missing` are review | cop plus review |

## Ignore
`**/vendor/**`, `**/tmp/**`, `**/log/**`, `**/coverage/**`.

## Layout
| Layout | Declare |
|---|---|
| Rails default (MVC by layer: `app/models`, `app/controllers`, `app/views`, `app/services`) | `layout: "Rails MVC folders; product areas spread across app/models, app/controllers and app/services"`, `areas` per PRD area by file name (`app/**/order*.rb`, `app/views/orders/**`), `map_dirs: ["app/models", "app/controllers", "app/services"]` |
| Packwerk (`packs/<p>/app/...`) or Rails engines | `layout: "Packwerk packs, one per domain under packs/"`, `areas: {"<p>": ["packs/<p>/**"]}` or `feature_root: "packs"` |
| Gem or plain Ruby (`lib/<gem>/<feature>.rb`) | `layout: "Gem with one file or folder per feature under lib/<gem>"`, `areas` per subfolder of `lib/<gem>` |
| Sinatra or Hanami slices (`slices/<s>/`) | `layout: "Slices under slices/, one per domain"`, one area per slice |

## Test naming
- `tests.mirror_patterns`: `["{name}_spec", "{name}_test"]`; `tests.match_symbol: true` (Zeitwerk and `require` autoload mean specs name the constant, not the path).
- Specs live in `spec/` mirroring `app/` and `lib/` (`spec/models/order_spec.rb`), Minitest in `test/` (AR10); in packs, `packs/<p>/spec/`.
- `tests.junit_xml`: `bundle exec rspec --format RspecJunitFormatter --out reports/junit.xml` (gem `rspec_junit_formatter`); Minitest: `minitest-ci` or `minitest-reporters` `JUnitReporter` (look up).

## Generated files
`generated_patterns`: `db/schema.rb`, `db/structure.sql`, `sorbet/rbi/**`, `**/*_pb.rb`, `public/assets/**`, `app/assets/builds/**`. Markers: `db/schema.rb` writes `# This file is auto-generated from the current state of the database`; protobuf writes `# Generated by the protocol buffer compiler.  DO NOT EDIT!`; Sorbet RBI writes `# DO NOT EDIT MANUALLY`.

## Framework exemptions
- `unique_name_exempt`: `application_record.rb`, `application_controller.rb`, `application_helper.rb`, `application_job.rb`, `application_mailer.rb`, `routes.rb`, `schema.rb`, `spec_helper.rb`, `rails_helper.rb`, `Gemfile`, `Rakefile`, `version.rb`.
- AR04: `ApplicationRecord`, `ApplicationController`, `ActiveJob::Base`, `Struct` and the concerns Rails requires (`include`d modules) are allowed; deep custom hierarchies are not.
- AR05: `Current` attributes (`ActiveSupport::CurrentAttributes`), `Rails.cache`, `ActiveRecord` models and constants frozen with `.freeze` count as explicit; class variables (`@@`) and global `$` variables are review.
- `id_header_lines`: default; the ID goes in a comment above the class.

## Snapshots
Agents never run the snapshot update mode of the project's gem (look up its flag or env var), and never re-record or delete VCR cassettes to make a test pass. Globs: `spec/fixtures/vcr_cassettes/**`, `**/__snapshots__/**`, `spec/snapshots/**`, `**/*.approved.*`.

## Contracts
- Rails schema: `db/schema.rb` (or `db/structure.sql`) is the snapshot, produced by `bin/rails db:schema:dump`; the file is read as is, and the `contracts` command can print it after a `db:schema:dump` into a temporary database (look up the project's setup).
- API: `rswag` (`bundle exec rake rswag:specs:swaggerize` writes `swagger/v1/swagger.yaml`) or `grape-swagger` / `committee` (look up).
- Routes: `bin/rails routes` output as a snapshot.

## Setup
`commands.setup`: `bundle install` (with `BUNDLE_FROZEN=true` in CI), then `bin/rails db:setup` when the unit tier needs a database (prefer the in-memory or test database from the offline guard).
