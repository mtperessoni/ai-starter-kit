## Structure enforcement
- Function length (AR03): clippy `too_many_lines` (pedantic) with `too-many-lines-threshold = 80` in `clippy.toml`; file length by `scripts/ratchet.py`.
- Import direction (AR09): crate boundaries in the workspace (a crate cannot import what it does not depend on); inside a crate, `pub(crate)` and module privacy.
- AR04 does not apply; AR05: review `static mut` and interior mutability shared across modules.
- Baseline: `#[allow(clippy::too_many_lines)]` on existing offenders, listed and removed wave by wave.

| Rule | Tool | Baseline |
|---|---|---|
| AR24 complexity | clippy `cognitive_complexity` (nursery, `cognitive-complexity-threshold = 10` in `clippy.toml`), `too_many_arguments` (`too-many-arguments-threshold = 5`), `excessive_nesting` (`excessive-nesting-threshold = 4`) | `#[allow(...)]` list, shrink-only |
| AR25 dead code | the compiler's `dead_code` and `unused` lints with `-D warnings`; `cargo machete` or `cargo udeps` for unused dependencies | `#[allow(dead_code)]` list with reasons |
| AR26 duplicates | `jscpd` or PMD CPD (`--language rust`); look up a Rust-native tool | report of today |
| AR27 typing | not applicable (statically typed) | |
| AR22 dispatch | trait objects and macros are named; `dyn Any` downcasts and `libloading` by computed name are review; clippy `disallowed_methods` can ban a fixed set | review |

## Offline guard
Traits and fakes in unit tests; network and database tests live in `tests/` or behind a feature flag.

## Ignore
`**/target/**`, `Cargo.lock` (for gitleaks only).

## Layout
| Layout | Declare |
|---|---|
| Cargo workspace, one crate per area (`crates/<c>/`) | `layout: "Cargo workspace, one crate per product area under crates/"`, `areas: {"<c>": ["crates/<c>/**"]}`; a crate is an area and a map folder |
| One crate, modules by feature (`src/<feature>/mod.rs`) | `layout: "One crate, one module per feature under src/"`, `feature_root: "src"` when every submodule is a feature |
| One crate, modules by layer (`src/handlers/`, `src/models/`, `src/db/`) | `layout: "One crate; src/ split by role (handlers, models, db) with product areas spread across them"`, `areas` per PRD area by file name, `map_dirs` the layer folders |
| `src/bin/<name>.rs` and `src/lib.rs` | `layout: "Library in src/lib.rs plus binaries in src/bin"`, `map_dirs: ["src/bin"]` |

## Test naming
- `tests.mirror_patterns`: `["{name}_test", "{name}"]` for files in `tests/` (integration tests are named after the module or behavior they prove); `tests.match_symbol: true` when `tests/` files import `crate::<module>`.
- Unit tests are inline in `#[cfg(test)] mod tests` and count toward the module's size (AR03): when the test block grows, move it to `<module>/tests.rs` (`#[cfg(test)] mod tests;`). Integration tests in `tests/<name>.rs`; doc tests in comments.
- `tests.junit_xml`: `cargo nextest run --profile ci` with `[profile.ci.junit] path = "junit.xml"` in `.config/nextest.toml`; the file lands in `target/nextest/ci/junit.xml`.

## Generated files
`generated_patterns`: `**/*.pb.rs`, `**/generated/**`, `**/bindings.rs` (bindgen), `**/schema.rs` (diesel print-schema). Markers: prost and tonic write `// This file is @generated by prost-build.`; bindgen writes `/* automatically generated by rust-bindgen`; diesel writes `// @generated automatically by Diesel CLI.` Build-script output in `OUT_DIR` is not in the tree.

## Framework exemptions
- `unique_name_exempt`: `mod.rs`, `lib.rs`, `main.rs`, `build.rs`, `prelude.rs`, `error.rs`, `tests.rs`.
- AR04 not applicable. Trait implementations the framework requires (`Serialize`, `Deserialize`, `Drop`, `FromRequest`) are not state or inheritance.
- AR05: `static` with `OnceLock`, `LazyLock`, `Atomic*`, `Mutex` behind a named accessor counts as explicit; `static mut` is review. Tokio actors and channels are explicit.
- `id_header_lines`: files open with `use` lines and module docs: put the ID in the `//!` module doc comment at the top.

## Snapshots
Agents never run `cargo insta accept`, `cargo insta test --accept`, `INSTA_UPDATE=always`, `UPDATE_EXPECT=1` (expect-test) or `TRYBUILD=overwrite`. Globs: `**/snapshots/*.snap`, `**/*.snap.new`, `tests/ui/*.stderr`.

## Contracts
- API: `utoipa` or `aide` generate OpenAPI: a binary or test that prints `ApiDoc::openapi().to_pretty_json()` into `docs/contracts/openapi.json`; gRPC: the `.proto` files.
- Database: diesel `src/schema.rs` is the snapshot; sqlx `cargo sqlx prepare` writes `.sqlx/`; otherwise `pg_dump --schema-only`.
- Public API of a library crate: `cargo public-api` (look up) or `cargo semver-checks`.

## Setup
`commands.setup`: `cargo fetch --locked` (plus `cargo build --workspace --all-targets` to warm the cache when the budget allows).
