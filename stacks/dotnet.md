# .NET

## Detect
| Signal | Means |
|---|---|
| `*.sln`, `*.csproj` | projects; test projects reference `Microsoft.NET.Test.Sdk` |
| xUnit, NUnit or MSTest packages | test framework; `[Trait("Category","Integration")]` or `[Category]` separates tiers |
| `.editorconfig`, `Directory.Build.props` | analyzers and style already configured |

## Structure enforcement
- Method length (AR03): SonarAnalyzer.CSharp rule `S138` (functions should not have too many lines) set to 80; file length by `scripts/ratchet.py`.
- Import direction and inheritance (AR04, AR09): NetArchTest or ArchUnitNET tests in the test tier.
- Baseline: rule severities as warnings plus a shrink-only suppression file; promote to errors per wave.

| Rule | Tool | Baseline |
|---|---|---|
| AR24 complexity | CA1502 (excessive complexity, threshold in `CodeMetricsConfig.txt`: `CA1502: 10`), CA1505, SonarAnalyzer `S3776` (cognitive), `S107` (parameters, max 5) | `GlobalSuppressions.cs` or `.editorconfig` severities, shrink-only |
| AR25 dead code | IDE0051 (unused private member), IDE0052, CS8019 (unused using), CA1812 (uninstantiated internal class), with `EnforceCodeStyleInBuild` | as above |
| AR26 duplicates | `jscpd` (supports C#) or PMD CPD (`--language cs`) | report of today |
| AR27 typing | not applicable (statically typed); nullable reference types: `<Nullable>enable</Nullable>` per project, `<WarningsAsErrors>nullable</WarningsAsErrors>`, enabled project by project and never removed | list of projects still without it |
| AR22 dispatch | `Activator.CreateInstance(Type.GetType(name))`, `GetMethod(name).Invoke`, `Assembly.Load` by computed name: BannedApiAnalyzers (`BannedSymbols.txt`) for a fixed set, rest is review | analyzer plus review |

## Offline guard
Unit tests use fakes; integration tests carry the Integration category. Under the offline flag, an `HttpMessageHandler` that throws can be registered in the test host.

## Ignore
`**/bin/**`, `**/obj/**`.

## Layout
| Layout | Declare |
|---|---|
| Clean architecture, one project per layer (`Domain`, `Application`, `Infrastructure`, `Web`) | `layout: "Clean architecture, one project per layer; product areas spread across the projects"`, `areas` per PRD area by file name or by folder inside each project (`**/Orders/**`), `map_dirs` the project folders |
| Vertical slices (`Features/<F>/` with command, handler, validator) | `layout: "Vertical slices under Features/, one folder per use case group"`, `feature_root` the `Features` folder |
| ASP.NET MVC (`Controllers/`, `Models/`, `Views/`) | `layout: "ASP.NET MVC folders (Controllers, Models, Views); product areas spread across them"`, `areas` by file name per PRD area, `map_dirs` those folders |
| One project per bounded context in a solution | `layout: "Solution with one project per bounded context"`, one area per project: `areas: {"<p>": ["src/<p>/**"]}` |

## Test naming
- `tests.mirror_patterns`: `["{name}Tests", "{name}Test"]`; `tests.match_symbol: true` (`using` names namespaces, so a test refers to the class, not the file).
- Tests live in a test project that mirrors the source tree (`tests/<Project>.Tests/<same folders>/`) (AR10).
- `tests.junit_xml`: `dotnet test --logger "junit;LogFilePath=reports/junit.xml"` (package `JunitXml.TestLogger`), or the built-in `--logger "trx;LogFileName=junit.trx"` (TRX is not JUnit: look up a converter before pointing the flag at it).

## Generated files
`generated_patterns`: `**/*.g.cs`, `**/*.Designer.cs`, `**/*.generated.cs`, `**/Migrations/*.cs`, `**/obj/**`, `**/Reference.cs` (service references). Markers: `// <auto-generated>` (standard, honored by analyzers), `[GeneratedCode]`.

## Framework exemptions
- `unique_name_exempt`: `Program.cs`, `Startup.cs`, `GlobalUsings.cs`, `AssemblyInfo.cs`, `_Imports.razor`, `Index.cshtml`, `appsettings.json`.
- AR04: `ControllerBase`, `DbContext`, `Hub`, `BackgroundService`, `Migration`, `Exception` and abstract test bases are allowed.
- AR05: DI singletons with mutable fields are review; `ConcurrentDictionary`, `IOptions`, `IMemoryCache`, Blazor component state, Redux-style stores count as explicit.
- `id_header_lines`: files open with `using` lines and a namespace: raise it (for example 25) or put the ID in the XML doc comment of the type.

## Snapshots
Agents never accept Verify output (`*.received.*` renamed to `*.verified.*`, `VerifierSettings.AutoVerify`, the `verify accept` tool, `DiffEngine` auto-accept) or Snapper updates. Globs: `**/*.verified.*`, `**/*.received.*`, `**/__snapshots__/**`.

## Contracts
- ASP.NET: Swashbuckle CLI `dotnet swagger tofile --output docs/contracts/openapi.json <dll> v1`, or NSwag; a test using `WebApplicationFactory` that fetches `/swagger/v1/swagger.json` also works.
- Database: EF Core `dotnet ef migrations script --idempotent` prints the full DDL; or a model snapshot `*ModelSnapshot.cs` as the file.

## Setup
`commands.setup`: `dotnet restore` (plus `dotnet tool restore` when `.config/dotnet-tools.json` exists).
