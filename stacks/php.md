## Structure enforcement
- PHPMD `ExcessiveMethodLength` (minimum 80), `ExcessiveClassLength` (300).
- Import direction (AR09): `deptrac` layers, one per feature.
- Baseline: PHPStan baseline file, deptrac `skip_violations`; shrink-only.

| Rule | Tool | Baseline |
|---|---|---|
| AR24 complexity | PHPMD `CyclomaticComplexity` (reportLevel 10), `NPathComplexity`, `ExcessiveParameterList` (minimum 5), PHPStan `phpstan-strict-rules`; nesting depth is review (PHPMD has no depth rule, look up) | PHPMD baseline (`--generate-baseline`), shrink-only |
| AR25 dead code | PHPStan (unused private members rules; look up a dead-code tool if unsure), Psalm `--find-unused-code` and `--find-unused-psalm-suppress`; `composer-unused` for dependencies | `psalm-baseline.xml` or PHPStan baseline |
| AR26 duplicates | PHPCPD (`phpcpd --min-lines 10 src`, archived: look up the maintained fork) or `jscpd` or PMD CPD | report of today |
| AR27 typing | `declare(strict_types=1)` in every file (rule `declare_strict_types` in php-cs-fixer); PHPStan level raised per module via a `phpstan.neon` per path or Psalm `errorLevel` (lower is stricter); the level only goes up | level per module recorded |
| AR22 dispatch | PHPStan `disallowed-calls` (`phpstan-disallowed-calls`) for `call_user_func`, `eval`, `extract`, `$$var` variable variables, `new $class`; Laravel facades and container resolution by convention go to the TRD | linter plus review |

## Offline guard
HTTP client fakes (`Http::fake()` in Laravel, mock handlers in Guzzle); integration tests in the `integration` group.

## Ignore
`**/vendor/**`, `**/storage/**`, `**/bootstrap/cache/**`.

## Layout
| Layout | Declare |
|---|---|
| Laravel default (`app/Models`, `app/Http/Controllers`, `app/Services`) | `layout: "Laravel default folders; product areas spread across app/Models, app/Http/Controllers and app/Services"`, `areas` per PRD area by file name (`app/**/Order*.php`), `map_dirs: ["app/Models", "app/Http/Controllers", "app/Services"]` |
| Laravel modules (`app/Modules/<M>/`, nwidart `Modules/<M>/`) | `layout: "Laravel modules, one folder per domain"`, `areas: {"<M>": ["Modules/<M>/**"]}` or `feature_root: "app/Modules"` |
| Symfony bundles or `src/<Context>/` (DDD) | `layout: "Symfony src/ with one folder per context"`, `feature_root: "src"` when each subfolder is a context |
| WordPress plugin or theme | `layout: "WordPress plugin or theme with includes/ and src/ folders"`, `map_dirs` the `includes/` and `src/` folders |

## Test naming
- `tests.mirror_patterns`: `["{name}Test"]`; `tests.match_symbol: true` (PSR-4 `use` statements name the class).
- Tests live in `tests/` mirroring `src/` or `app/` (`tests/Unit`, `tests/Feature` in Laravel) (AR10).
- `tests.junit_xml`: `vendor/bin/phpunit --log-junit reports/junit.xml`; Pest: `--log-junit` as well.

## Generated files
`generated_patterns`: `bootstrap/cache/**`, `**/_ide_helper*.php`, `.phpstorm.meta.php`, `var/cache/**`, `**/*Proxy.php`, protobuf `GPBMetadata/**`, `database/migrations/*` only when machine-made. Markers: protobuf writes `# Generated by the protocol buffer compiler.  DO NOT EDIT!`; for ide-helper and others look up the header; when it matches none of the ratchet's default marker regex, set `generated_marker` in `ai-kit.json`.

## Framework exemptions
- `unique_name_exempt`: `index.php`, `routes/web.php`, `routes/api.php`, `Kernel.php`, `Controller.php`, `Handler.php`, `ServiceProvider.php`, `AppServiceProvider.php`, `TestCase.php`.
- AR04: Eloquent `Model`, `Controller`, `FormRequest`, `Command`, `Mailable`, Doctrine entities, `Exception` and abstract `TestCase` are allowed; traits the framework documents (`HasFactory`, `Notifiable`) are allowed.
- AR05: `config()`, the service container bindings, `Cache`, `Session`, Eloquent models and Symfony services count as explicit; `static` properties and `global` are review.
- `id_header_lines`: files open with `<?php`, `declare` and `namespace` plus `use` lines: raise it (for example 25) or put the ID in the class docblock.

## Snapshots
Agents never run the snapshot update mode: `--update-snapshots` (Pest, spatie phpunit-snapshot-assertions; look up the project's exact flag) or auto-approve in ApprovalTests. Globs: `**/__snapshots__/**`, `tests/**/*.snap`, `tests/**/*.approved.*`.

## Contracts
- Laravel: `php artisan route:list --json` for routes; OpenAPI by `l5-swagger` (`php artisan l5-swagger:generate`) or `dedoc/scramble` (`php artisan scramble:export`), look up the project's tool.
- Symfony: `bin/console nelmio:apidoc:dump --format=json`.
- Database: `php artisan schema:dump` (writes `database/schema/*.sql`) or Doctrine `bin/console doctrine:schema:create --dump-sql`.

## Setup
`commands.setup`: `composer install --no-interaction --prefer-dist` (plus `cp .env.example .env && php artisan key:generate` for Laravel).
