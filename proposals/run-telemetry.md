# Proposal: run telemetry and retrospective

Status: adopted on 2026-10-05. Every agent run in a project leaves summarized artifacts, grouped by the change it served; at the end of a delivery a retrospective names what was slow, expensive, looping or wasteful. A run within every threshold produces no finding.

## Sources
| Source | Status | Gives |
|---|---|---|
| Claude Code hooks | Documented; verified on 2.1.178 | Every tool call (duration, error, agent), subagents (tokens, duration, tool count, transcript path), compactions, waits, session start and end |
| Session transcript | Internal format, may change | Main-thread tokens and context per request; enrichment only, never required |
| `run_probe.py` and `gates.sh` | This change | Test target, tests collected, memory peak, disk and Docker deltas |

## Rules
| ID | Rule |
|---|---|
| RT01 | Artifacts live in `.ai-kit/runs/<context>/` (git-ignored): `meta.json`, `events.jsonl`, `resources.jsonl`, and the retro outputs `spans.jsonl`, `summary.json`, `retro.md`. When the context is a change folder, `retro.md` is also copied to `changes/NNN-<slug>/retro.md`, which is committed and archived with the change |
| RT02 | Context, first match wins: env `AI_KIT_CONTEXT`; the first line of `.ai-kit/runs/current` (written by `scripts/gates.sh context <name>` and by prd-gate step 1 with the slug); the git branch with `/` turned into `-`; `default` |
| RT03 | `scripts/telemetry_hook.py` is the only hook command, registered in `.claude/settings.json` with `"async": true` for SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, PostToolUseFailure, SubagentStart, SubagentStop, Notification, PreCompact, PostCompact, Stop, SessionEnd. It reads stdin, appends one line to `events.jsonl`, prints nothing and always exits 0, in under 100 ms; any exception is swallowed |
| RT04 | Event line (only the keys that apply): `ts` (epoch seconds, float), `ev` (hook event name), `sid` (session id, first 8 chars), `agent` (agent_id or `main`), `atype` (agent_type), `tool`, `tuid` (tool_use_id), `cls` (RT05), `cmd` (first 160 chars of the command or of the file path or pattern, secrets redacted), `h` (sha1 of the full tool_input, first 12 chars), `files` (paths touched by Edit, Write, MultiEdit), `ms` (duration_ms), `err` (true on PostToolUseFailure), `intr` (is_interrupt), `out_kb` (size of stdout plus stderr or of the response), `sub` (Agent result: `tokens`, `ms`, `tools`, `status`, `id`), `tp` (transcript_path on SessionStart, agent_transcript_path on SubagentStop), `trigger`, `ctx_before`, `ctx_after` (compactions), `ntype` (notification type), `bg` (background task count on Stop), `ver` (Claude Code version when known). Tool outputs are never stored |
| RT05 | Command classes: `test.related`, `test.full`, `test.single` (from the `gates.sh` target when the command goes through it, else from the runner and its arguments), `test.other`, `docker.build`, `docker.run`, `docker.other`, `git`, `install` (package managers), `background.unbounded` (`tail -f`, endless loops), `shell`; other tools use their lowercase name; `askuserquestion` and notification waits are `wait.human` |
| RT06 | Redaction before writing: `KEY=value` where the key contains TOKEN, SECRET, PASSWORD, KEY or AUTH; bearer tokens; strings matching common key prefixes (`sk-`, `ghp_`, `gho_`, `AKIA`) become `***` |
| RT07 | `scripts/run_probe.py --label <target> -- <cmd...>` runs the command, streams its output unchanged, returns its exit code, and appends one line to `resources.jsonl`: `ts`, `label`, `cmd` (redacted, 160 chars), `exit`, `sec`, `mem_peak_mb` (process tree: psutil when installed, else `/proc` sampling on Linux, else the child's peak working set on Windows, else null), `disk_free_gb_before`, `disk_free_gb_after`, `tests_collected`, `tests_failed` (parsed from pytest, unittest, jest or vitest summaries when present), `agent` (env `CLAUDE_AGENT_ID` when set, else null) |
| RT08 | `scripts/gates.sh` runs `related`, `one`, `offline`, `integration`, `full` and `build` through `run_probe.py` with the target as label, and gains `context <name>` and `retro [--context <name>] [--prune]` |
| RT09 | `scripts/retro.py [--context <name>] [--root .] [--prune]` reads `events.jsonl`, `resources.jsonl` and, when present, the transcripts named in `tp`; writes `spans.jsonl` (one span per subagent and per test run, plus the main thread), `summary.json` (totals per category and the top 5 lists) and `retro.md`; prints at most 15 lines. It never fails the caller: a missing source lowers the coverage, it does not raise |
| RT10 | `retro.md` order: **Coverage** (which sources fired, share of calls with a duration, share joined to tokens, probes seen, Claude Code version), **Findings** (only metrics past a threshold, each with severity, value, threshold, evidence as event `seq` numbers, agent and command, and the rule it breaks or `candidate`), **Time and tokens** (compact table: wall, agent work, human wait, tokens main and subagents, context peak), **Top 5** slowest calls, heaviest subagents, memory peaks. With no finding the Findings section says so in one line |
| RT11 | Thresholds live in `ai-kit.json` `telemetry` with defaults: `long_call_s` 300, `long_test_s` 300, `long_subagent_min` 30, `subagent_tokens` 150000, `subagent_tools` 50, `context_peak_tokens` 200000, `big_output_kb` 100, `loop_repeats` 3, `edit_repeats` 8, `error_rate` 0.15 (over at least 20 calls), `memory_mb` 2048, `disk_drop_mb` 1024, `dead_mb` 500, `max_events_mb` 5, `keep_days` 14 |
| RT12 | Detectors: `long_call` (excluding `wait.human`), `slow_test`, `full_suite_mid_task` (a `test.full` inside a subagent, or more than one before the last, TS03), `long_subagent`, `heavy_subagent` (tokens or tools past the ceiling, SA rules), `context_peak`, `auto_compaction`, `big_output`, `loop` (same `h` failing `loop_repeats` times, or one file edited `edit_repeats` times), `error_rate`, `memory`, `disk_drop`, `docker_outside_gates` (TS29), `unbounded_background` (TS34), `dead_files` (task output folders, temp project folders and stale worktrees past `dead_mb`), `killed_call` (a PreToolUse with no Post or Failure by session end) |
| RT13 | Limits: when `events.jsonl` passes `max_events_mb`, the oldest half is dropped and a `truncated` marker is written; `--prune` deletes run folders older than `keep_days` and those of archived changes; `clean-outputs` calls it |
| RT14 | prd-gate: step 1 writes the slug with `gates.sh context`; execution ends with `scripts/gates.sh retro` after the full suite; the final report (WF25) lists the findings, or says the run stayed within every threshold |

## Evaluation
`eval/telemetry/` installs the kit from `HEAD` into the small fixture and runs two unattended sessions with subagents: a clean one (expected: no finding) and one that provokes long calls, a full suite inside a subagent, a big output, a failing loop, a memory peak and a dead folder, with thresholds lowered to keep the run short (expected: each detector fires once with evidence, nothing else fires).
