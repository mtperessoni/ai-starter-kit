# A/B: current docs flow vs "rule as data, one commit"

Date 2026-10-14. Repository agora-consulta-fe at 46b66879, one git worktree per run. Scenario (C5, size M): the conversation reconnect window goes from 60 s to 90 s and the screen shows the seconds left. Sheet answer `ok` in every run (decision 1 = A: stop the attempt at zero). One shared surveyor run (unchanged by the proposal) fed both arms. Reviews were excluded from both arms. Two runs per arm. Raw data: `ledger.md`, `metrics.md`, `quality-*.txt`, `answers.md`, `suite-*.log`, `compare-*.log`.

- **A (current):** `prd-flow-docs apply` (Opus), approval of `diff.md`, baseline, executor T01, executor T02, compare, executor `close` with promote.
- **B (proposed):** one executor (Sonnet) under `contract-b.md`. The PRD rows, code and tests go in one commit, checked by `gate_lite.py` (5 checks).

## Verdict

The proposal is confirmed on efficiency. It cut elapsed time by about 70%, agent dispatches from 5.5 to 1, and docs churn by 85%, and it removed every docs gate failure. Code quality held: all tests and the full suite are green, and tsc is clean in B while A shipped a cross-task type break. On traceability it loses one thing, the decision record, which B must carry before adoption.

The current flow also showed defects that only it exposed:
- the "(today: ...)" residue that promote leaves behind, in both runs;
- the cross-task tsc break;
- baseline unusable on this machine: the 8.3 temp path breaks vite on `[triageId]`, and ANSI colors break the summary regex;
- the G28 sibling drift that every docs run had to reason about.

## Changes to the proposal before adoption

| ID | Change | Fixes |
|---|---|---|
| P1 | The commit body carries the decision lines from the sheet: `Decided: 1A stop the attempt at zero (rejected: show 0 s)` and the request in the user's words | Reader Q3 gap |
| P2 | The TRD never restates a rule value. The old-value Grep covers all of `docs/`, not only `docs/prd` | B2 stale TRD |
| P3 | The INDEX IDs column is generated by a script run in the commit hook, or dropped | B INDEX gap, G2 |
| P4 | Test first is checked: the commit body names the red run (`Red: <test> failed before`) | B2 skipped red |
| P5 | Hook and component logic gets a `.test.ts` beside it when it holds a rule | Missing hook test in 3 of 4 runs |

## Limits

- Two runs per arm.
- A small-docs repository: the FE PRD is 41 KB against 831 KB in clara-ai, so the gain there is likely larger.
- Reviews excluded.
- Contract B was on its first try.
- A used Opus for docs, as the current system does.
