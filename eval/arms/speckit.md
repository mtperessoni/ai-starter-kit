Product changes here start with /prd-gate (classification, PRD, TRD). For a rule change or a new feature, once the PRD and TRD are updated, run /speckit-specify, /speckit-plan and /speckit-tasks (/speckit-clarify only if questions remain), then implement the tasks of tasks.md test first, with one commit per task, following prd-gate's execution rules. Bugs and refactors go through /prd-gate only.
